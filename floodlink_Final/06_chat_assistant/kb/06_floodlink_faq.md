# คำถามเกี่ยวกับการใช้ FloodLink

## แจ้งขอความช่วยเหลือยังไง / แจ้งเหตุยังไง / ต้องทำยังไง
พิมพ์ในแชทนี้ได้เลย หรือกรอกที่หน้าแรกของเว็บ บอกตำแหน่ง เบอร์ติดต่อ จำนวนคน ผู้ป่วย ระดับน้ำ และสิ่งที่ต้องการ ระบบจะสร้างเคสส่งเข้าคิวศูนย์ประสานทันที และให้ลิงก์ติดตามเคส ถ้าข้อมูลยังไม่ครบ ผมจะถามเพิ่มทีละข้อ

## แจ้งแทนญาติได้ไหม / แจ้งแทนคนอื่น / ญาติติดอยู่
ได้ บอกตำแหน่งบ้านญาติ จำนวนคน ผู้ป่วย และเบอร์ของญาติ (หรือเบอร์คุณถ้าติดต่อญาติไม่ได้) ถ้าติดต่อญาติไม่ได้แล้ว ให้บอกด้วย ระบบจะให้ความสำคัญมากขึ้น

## ข้อมูลของฉันใครเห็นบ้าง / ใครเห็นเบอร์โทร / ความเป็นส่วนตัว / ข้อมูลส่วนตัว
ชื่อ เบอร์ ที่อยู่ และรูป เห็นเฉพาะเจ้าหน้าที่ศูนย์ประสาน และชุดกู้ภัยที่รับเคสของคุณเท่านั้น หน้าสาธารณะแสดงแค่ตัวเลขรวมรายพื้นที่ และก่อนส่งข้อความให้ AI ภายนอกช่วยอ่าน ระบบจะปิดบังเบอร์ บ้านเลขที่ พิกัด และชื่อก่อนเสมอ

## ทำไมเคสยังไม่มีทีม / ทำไมยังไม่มีคนมา / รอนานมาก / ทีมจะมาเมื่อไหร่
ศูนย์จัดทีมตามความเร่งด่วน เคสสีแดง (ผู้ป่วยติดเตียง ฟอกไต ทารก น้ำถึงหลังคา) ได้ก่อน ช่วยให้เร็วขึ้นได้โดยส่งข้อมูลที่ยังขาด โดยเฉพาะตำแหน่งที่ชัดและเบอร์ที่โทรติด ถ้าอาการใครแย่ลงหรือน้ำขึ้นเร็ว ให้แจ้งเพิ่มทันที และถ้าอันตรายถึงชีวิต โทร 1669 หรือ 1784

## ติดตามเคสยังไง / เช็กสถานะ / เคสของฉันถึงไหนแล้ว
เปิดลิงก์ติดตามที่ได้ตอนแจ้ง หรือพิมพ์ในแชทนี้ว่า "เคสฉันถึงไหนแล้ว" (ถ้าแจ้งจากแชทนี้) จะเห็นว่า ตรวจแล้ว มีทีมรับ หรือกำลังช่วย

## แจ้งซ้ำได้ไหม / แจ้งไปแล้วแจ้งอีกได้ไหม / ส่งข้อมูลเพิ่ม
ส่งข้อมูลเพิ่มของบ้านเดิมผ่านลิงก์ติดตามหรือพิมพ์ในแชทเดิมได้เลย ไม่ต้องแจ้งใหม่ ถ้ามีคนแจ้งบ้านเดียวกันซ้ำ ระบบจะรวมเป็นเคสเดียวให้

## ปลอดภัยแล้วต้องแจ้งไหม / ออกมาได้แล้ว / มีคนมารับแล้ว
ควรแจ้งครับ ทีมจะได้ไปช่วยบ้านอื่น พิมพ์ว่า "ปลอดภัยแล้ว" ในแชทนี้ หรือกดปุ่ม "ทุกคนปลอดภัยแล้ว" ในหน้าติดตามเคส

## หลายบ้านในข้อความเดียว / แจ้งหลายเคส
ส่งรวมกันได้ ขึ้นบรรทัดใหม่แล้วใส่ "เคส 1", "เคส 2" หน้าแต่ละบ้าน ระบบจะแยกเป็นหลายเคสให้
