# เตรียมตัวและอพยพ

## กระเป๋าฉุกเฉิน / ต้องเตรียมอะไรบ้าง / ของจำเป็น
ยาประจำตัวอย่างน้อย 7 วัน เอกสารสำคัญใส่ถุงกันน้ำ โทรศัพท์ พาวเวอร์แบงค์ ไฟฉาย ถ่าน นกหวีด น้ำดื่ม อาหารแห้ง เสื้อผ้า ผ้าห่ม ของใช้เด็กหรือผู้สูงอายุ และเงินสดเล็กน้อย

## อพยพผู้ป่วยติดเตียง / ผู้สูงอายุ / คนเดินไม่ได้
อพยพก่อนน้ำขึ้นสูง เพราะเรือเล็กรับผู้ป่วยติดเตียงได้ยาก แจ้งในแชทนี้ว่ามีผู้ป่วยติดเตียง ใช้ออกซิเจน หรือฟอกไต จะได้เป็นเคสเร่งด่วน เตรียมยา เอกสารการรักษา และอุปกรณ์การแพทย์ไปด้วย

## สัตว์เลี้ยง / หมา / แมว ติดในบ้าน
ถ้าพาไปได้ ให้พาไปด้วยพร้อมสายจูงหรือกรง ถ้าต้องทิ้งไว้ ให้วางไว้ที่สูง มีน้ำและอาหาร อย่าล่ามติดกับที่ ความปลอดภัยของคนต้องมาก่อน ถ้าแจ้งขอเรือ บอกด้วยว่ามีสัตว์เลี้ยงกี่ตัว

## รถยนต์ / รถจมน้ำ / ย้ายรถ
ย้ายรถไปที่สูงก่อนน้ำมา อย่าขับฝ่าน้ำที่ไม่รู้ความลึกหรือไหลแรง ถ้ารถจมน้ำแล้ว อย่าสตาร์ทเครื่อง ให้ช่างตรวจก่อน ถ่ายรูปความเสียหายไว้ใช้เคลมประกัน

## ไฟดับ / ไม่มีไฟ / แบตใกล้หมด
ปิดแอปที่ไม่ใช้ ลดความสว่างจอ เปิดโหมดประหยัดพลังงาน นัดเวลาเปิดเครื่องกับญาติ ใช้ไฟฉายแทนเทียนถ้าทำได้ ถ้าเห็นสายไฟขาดลงน้ำ อยู่ห่าง ๆ และแจ้งการไฟฟ้า
