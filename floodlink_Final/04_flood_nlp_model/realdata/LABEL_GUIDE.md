# คู่มือติดป้ายข้อมูล FloodLink (ใช้ทั้งคนและ LLM)

หลักการข้อแรก: **ติดป้ายตามสิ่งที่ข้อความเขียนไว้เท่านั้น** ห้ามเดา ถ้าข้อความไม่ได้บอก ให้เว้นว่างหรือตอบ `null`

## 1. message_type (ต้องเลือก 1 อย่าง)
| ค่า | ใช้เมื่อ | ตัวอย่าง |
|---|---|---|
| `help_request` | ขอความช่วยเหลือให้ตัวเองหรือคนอื่น (อพยพ อาหาร ยา หาตัวคนที่ติดต่อไม่ได้) | "ยายติดเตียง น้ำถึงชั้น 2 ซ.8", "ติดต่อแม่ไม่ได้ 3 วัน อยู่โชคสมาน 5" |
| `status_update_resolved` | แจ้งว่าได้รับการช่วยแล้ว ออกมาแล้ว หรือปลอดภัยแล้ว | "ซ.11 รัตนอุทิศ ได้รับการช่วยเหลือแล้วค่ะ ขอบคุณ" |
| `hazard_report` | แจ้งจุดอันตราย (ไฟรั่ว น้ำเชี่ยว สัตว์อันตราย) โดยไม่ได้ขอให้ช่วยคน | "ระวังไฟรั่วหน้าเซเว่น ถ.เพชรเกษม" |
| `donation_offer` | เสนอเรือ แรงงาน ของ หรือที่พัก | "มีเรือว่าง 2 ลำ อยู่ มอ." |
| `irrelevant` | ให้กำลังใจ ถามข่าว แสดงความเห็น ประกาศเบอร์หน่วยงาน หรือข้อความที่ไม่มีเนื้อหา (เช่น "ช่วยเพื่อนด้วยค่ะ" ที่มีแต่รูป) | "สู้ ๆ นะคะ", "ทำไมหน่วยงานไม่ไป" |

- ข้อความผสม (ให้กำลังใจ + ขอช่วย) → `help_request`
- "ช่วยเพื่อนด้วยค่ะ" ที่ไม่มีตำแหน่งหรือรายละเอียดเลย → `help_request` + `insufficient_info=true`

## 2. flags (กลุ่มเปราะบาง เลือกได้หลายอย่าง)
| ค่า | คำที่พบบ่อย |
|---|---|
| `bedridden` | ติดเตียง, นอนติดเตียง, เดินไม่ได้เลย, อัมพาต |
| `wheelchair` | นั่งรถเข็น, เดินลำบาก, ขาไม่ดี |
| `disabled_blind` | ตาบอด, พิการ, หูหนวก |
| `dialysis` | ฟอกไต, ล้างไต, ไตวายต้องฟอก |
| `heart` | โรคหัวใจ |
| `pregnant` | ตั้งครรภ์, ท้อง X เดือน |
| `in_labor` | ปวดท้องจะคลอด, น้ำเดิน, ใกล้คลอดมาก |
| `injured` | บาดเจ็บ, เลือดออก, กระดูกหัก, แผลใหญ่ |
| `chronic_illness` | มีโรคประจำตัว, ความดัน, เบาหวาน, หอบหืด, อัลไซเมอร์ |
| `sick_now` | ป่วยตอนนี้: ไข้สูง, หายใจไม่ออก, ชัก, ขาดยาแล้วอาการแย่ |
| `cannot_swim` | ว่ายน้ำไม่เป็น (บอกไว้ชัดเจน) |

## 3. ข้อมูลอื่น
- `water_level`: `knee` / `waist` / `chest` / `floor1` (มิดชั้น 1) / `floor2` (ถึงชั้น 2) / `roof` (บนหลังคา หรือจะมิดหลังคา) / `null`
- `adults`: จำนวนผู้ใหญ่ทั้งหมด รวมผู้สูงอายุ ไม่รวมเด็ก ถ้าไม่บอกให้ใส่ `null`
- `children_ages`: อายุเด็กเป็นปี เช่น 6 เดือน = 0.5 ถ้าบอกว่า "มีเด็ก 2 คน" แต่ไม่บอกอายุ ให้ใส่ `children_count=2`
- `elderly_ages`: อายุผู้สูงอายุ (60 ปีขึ้นไป) ถ้าบอกแค่ "คนแก่ 2" ให้ใส่ `elderly_count=2`
- `days_trapped`: ติดมากี่วัน
- `needs`: `evacuation` / `food` / `water` / `milk` / `medicine` / `power` (แบต ไฟ) / `medical` (ต้องการหมอหรือพาไปโรงพยาบาล)
- `lost_contact`: ผู้แจ้งติดต่อคนในบ้านไม่ได้
- `reporter`: `self` (ผู้ประสบภัยแจ้งเอง) / `relative_or_friend` (ญาติหรือเพื่อนแจ้งแทน) / `third_party` (แชร์ต่อ) / `unknown`
- `n_cases`: จำนวนบ้านหรือเคสแยกกันในข้อความ
- `insufficient_info`: ไม่มีตำแหน่งเลย หรือไม่รู้ว่าเกิดอะไรขึ้น จนทีมไปช่วยไม่ได้
- `person_names`: ชื่อคนที่ยังเหลืออยู่ในข้อความ (ใช้ปิดบังข้อมูล ไม่ได้ใช้เทรน)

## 4. priority (คนติดป้ายตัดสิน ใช้เทียบกับสีที่กฎคำนวณได้)
| สี | เมื่อไร |
|---|---|
| `red` | อันตรายถึงชีวิตตอนนี้: ฟอกไตขาดรอบ, หัวใจ, บาดเจ็บ, `in_labor`, `sick_now` ที่รุนแรง, ทารก < 1 ปี, ติดเตียง + น้ำถึงชั้น 2 หรือหลังคา, อยู่บนหลังคาหรือน้ำกำลังจะมิด, ท้อง + น้ำมิดชั้น 1 ขึ้นไป |
| `orange` | กลุ่มเปราะบาง: ติดเตียง, พิการ, ตั้งครรภ์, ผู้สูงอายุ 70+, เด็ก < 6 ปี, น้ำถึงชั้น 2, ติดต่อไม่ได้ + มีกลุ่มเปราะบาง |
| `yellow` | ติดค้างและขาดอาหาร น้ำ หรือยา, ติดมา 2 วันขึ้นไป, น้ำถึงเอวหรือมิดชั้น 1 |
| `green` | ต้องการของ แต่ไม่เร่งด่วน |
| `none` | ไม่ใช่ `help_request` |

ถ้าข้อมูลไม่พอให้เลือกสีตามสิ่งที่รู้ แล้วตั้ง `insufficient_info=true` ห้ามเดาว่าแย่กว่าที่เขียน

## 4.1 กฎเพิ่มจากการตรวจชุดทดสอบรอบแรก (ข้อผิดพลาดที่พบบ่อย)
| กรณี | ติดป้ายแบบนี้ |
|---|---|
| "ติดอยู่ชั้น 2" / "อยู่ชั้น 2" | คนอยู่ชั้น 2 **ไม่ใช่** น้ำถึงชั้น 2 (`water_level` = floor2 เฉพาะเมื่อบอกว่าน้ำถึง/จะถึงชั้น 2) |
| "ทารก" "เด็กแรกเกิด" "X เดือน" | อายุต่ำกว่า 1 ปี → **red** |
| "เด็กเล็ก" | ถือว่าต่ำกว่า 6 ปี → อย่างน้อย orange |
| เด็กมีไข้/ตัวซีด, คนแก่ "ไม่ไหวแล้ว"/เป็นลม/หมดสติ | `sick_now` → red |
| ไม่ได้ฟอกไต / ล้ม / กระดูกหัก | `dialysis` / `injured` → red |
| ติดต่อไม่ได้อย่างเดียว | yellow (ถ้ามีเด็กเล็ก/ผู้สูงอายุ/ผู้ป่วยด้วย → orange) |
| help_request | ต้องมีสีเสมอ ห้ามใส่ none |
| มีบ้านเลขที่ / ซอย / ชื่ออาคาร | `insufficient_info` = false |
| "ฝากเคสนี้" "ฝากน้องด้วย" "ช่วยไปส่งอาหาร" | help_request |

## 5. ตอนตรวจชุดทดสอบ (คน)
- แก้เฉพาะช่องที่ผิด แล้วใส่ `reviewed=1`
- ถ้าตัดสินใจไม่ได้ ให้เขียนในช่อง `review_note` แล้วข้ามไป ห้ามเดา
- ทีมควรตรวจชุดเดียวกัน 50 ข้อความก่อน แล้วเทียบกันว่าตรงกันกี่ % ถ้าต่ำกว่า 85% ให้คุยกันแล้วแก้คู่มือนี้ก่อนตรวจที่เหลือ
